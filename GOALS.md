## G-001 — Hauptziel

> **Diesen Fork (`st0rax/jewtube`) zum Bazaar-Heim für jewtube-Arbeit unter
> st0rax machen** — ohne so zu tun, als sei das Produkt schon umgezogen.

- **Stand (geprüft, README):** Der One-Liner bootstrapped weiterhin
  `jewtube_installer` von **stoorax/jewtube** (Parent). Dieser Baum ist ein
  öffentlicher Fork mit derselben Datei lokal. Die Produkt-Quelle ist nicht
  stillschweigend hierher gewandert.
- **Was:** Bazaar-Prozess auf **main** (START_HERE → GOALS → WORK_CONTRACT →
  TASKBOARD.json), Identitäten `@jewtube.local`, ehrliche nächste Schritte
  als freie Zellen — z. B. ob der README später auf den Fork-Installer
  zeigen soll.
- **Wie:** freiwillige kleine Schritte über `docs/TASKBOARD.json` (Kanten =
  `depends_on`; niemand zieht eine verkettete Aufgabe parallel). JSON ist
  die einzige Claim-Tafel.
- **Erfolg:** Docs konsistent, JSON gültig, `main` grün, Parent unangetastet.
  Kein Dummy-`cargo test`.

- Änderungen an G-001 nur durch den Menschen.
